# 💰 Personal Expense Tracker

A beginner-friendly Python application that helps users manage their daily expenses and track their budgets.

## 📌 About the Project

The Personal Expense Tracker is a command-line application developed using Python. It allows users to record expenses, view spending history, calculate total expenses and monitor their remaining budget.

## ✨ Features

- Add new expenses.
- View all recorded expenses.
- Calculate total spending.
- Set a budget.
- Calculate remaining budget.
- Warning when the budget is exceeded.
- Permanently save expenses using file handling.
- Reset all saved expenses.

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python expense_tracker.py
```
